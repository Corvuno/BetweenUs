# Art Deco references

The owner's own reference images (owner, 2026-11-05: "If I do add them somewhere you can forever find
them"). Every looks round reads this folder first and names which references it drew from.

How images get here: the owner sends them in any session; that session saves each one here
(a short descriptive file name, e.g. `facade-stepped-tiers.jpg`) and adds one line below on what the
owner said about it. The owner may also add files directly on GitHub.
