# Desktop main screen fits the window — agreement, 2026-10-13

Owner's words: "the height of the desktop edition is too much, it scrolls … if there is a
fav bar." Then: "Fit the screen is better than scroll." and "Create some space between the
'Between Us' and the top as well, now looks crammed." "Fullscreen" meant the main screen in
a normal browser window, not the app's Full screen mode.

## B) Looks — looks-builder
- Desktop main screen (wide windows): the whole screen — title, card, buttons — fits inside
  the visible window at any height, with or without a bookmarks bar. No page scroll.
- On short windows the card keeps shrinking below its current minimum size rather than the
  page scrolling. (The owner expects the desktop look to get more width later; not now.)
- A clear gap between the top of the window and the "Between Us" title. The amount is
  picked by the owner from screenshots of a few options before it is built.

## Deliberately not changing
- Phone layout, the app's Full screen mode, card text, anything that isn't spacing/size.

## How the areas pull
- None. Looks only.

## Done when
- Measured at common desktop heights (e.g. 1920×969/937, 1536×730/698, 1440×789/757,
  1366×625): page height equals window height, nothing cut off, title has its top gap.
- Tests pass.
