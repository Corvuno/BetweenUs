# Designer notes

Mistakes the owner caught in design rounds, one line each. The designer reads this first and never
repeats one. A line is added each time the owner turns a design down.

- On PC, a sketch moved controls to the top but left one top corner light and piled the rest in the
  bottom centre: the four corners around the card each carry a group of matching weight.
- "Combine A, B and C" was drawn as one reading without saying so plainly enough; when a pick can be
  read two ways, draw the reading and name the other in one line.
