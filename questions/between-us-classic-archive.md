# Between Us — Classic Deck (archived)

Archived export of the original pre-rewrite question pool (`CLASSIC_CARDS` in the app,
played only when `window.CLASSIC_DECK = true`). Kept for safekeeping while the classic
deck is folded category-by-category into the current deck (`between-us-deck.md`).
Not the live deck. Dutch translations (`nl`) preserved where present.
